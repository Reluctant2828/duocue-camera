# DuoCue 0.2.0 · 素材导入与拍摄流程改进

## 使用方式

相机中轻点“选素材”，从“相册”或“文件”选择图片、GIF 或视频。导入成功后已自动选用；轻点缩略图可预览，确认后点“使用并返回相机”。图片保持显示，GIF/视频静音循环；可以切换完整显示或填满裁切。

相册中的 GIF 优先读取原始 GIF 数据，不经过 UIImage 转码。视频使用文件传递，不把整段视频放进内存。iCloud 文件会显示读取进度并允许取消。导入失败可以直接重新选择，原有素材不会被覆盖。

## 兼容与更新

- 桌面显示名仍为 ASCII `DuoCue`，图标保持猫猫相机，Bundle ID 仍为 `com.reluctant2828.duocue`。
- 旧版 GIF/视频目录、选择和显示方式继续读取。
- 在 SideStore 使用同一个 Apple 账号覆盖安装，保留素材与未保存拍摄；不要先卸载。
- GIF 必须仍是相册里的原始动图。如果其他软件已经把它保存成静态图片，App 只能显示静态图；可从“文件”导入原始 `.gif`。

## 本次审查修复

- 新增静态图片类型，纠正照片方向并按显示所需尺寸解码；GIF、图片、视频按实际内容识别，不依赖提供者的临时扩展名。
- 使用相册专用选择器和按格式读取路径，保留 GIF 的帧与时序；视频临时文件在回调返回前复制。
- 完整提供导入进度、取消、失败提示、选用状态、预览和返回相机流程。
- 修复等待麦克风授权后过期的录制请求意外开始、重复停止及录像收尾状态。
- 横屏将拍摄控制放在侧边；临时关闭外屏显示不再改写用户的持久开关。
- 相册已保存成功但恢复索引清理失败时，不再留下无法导出的空条目。

## 验证

项目检查、29 项原生测试和横竖屏渲染检查用于本次回归；实际云端结果以验证记录为准。真实 Photos/iCloud 提供者、后置摄像头与 Duo 外屏仍需要覆盖安装后在手机上确认。
