# iPhone Duo 真机验收

以下是待执行清单，不表示已通过。记录手机型号、iOS 完整版本、App 版本、构建编号、测试日期及失败时的界面提示。请勿在日志或截图中包含账号密码。

## 1. 首次能力验证（先做）

- [ ] 云端用 Xcode 27.1 / iOS 27.1 SDK 编译通过，下载的 IPA 校验值一致。
- [ ] Windows USB 侧载成功，免费签名后 App 正常启动；开发者模式已开启。
- [ ] 展开 Duo，App 全屏显示于内屏，允许相机后出现实时后置相机取景。
- [ ] 开启内置外屏验证动画，外屏出现移动图案；拍摄对象所在方向正确。
- [ ] 拍照和录像时外屏继续播放；拍摄文件中不包含动画。
- [ ] 合拢、旋转和重新展开，系统允许时外屏恢复；系统不允许时内屏提示可用性，不出现卡死或黑屏误报。

此阶段不过，先解决签名/接口/设备链路，不把“外屏功能可用”作为交付结果。

## 2. 素材导入和播放

- [ ] 分别从相册与“文件”导入 GIF、MP4、MOV；取消选择不弹错误。
- [ ] GIF 非等间隔帧正常播放，短视频连续循环没有可见黑帧。
- [ ] 导入后删除原素材或撤回原文件位置访问，App 本地副本仍可播放。
- [ ] 缩略图、名称、预览和选择对应同一素材；退出重启仍保留所选素材和显示方式。
- [ ] 选中素材、切换完整显示/填满裁切，内外屏同步；删除正在使用的素材后切换到剩余素材，没有剩余素材时显示测试动画。
- [ ] 动画静音，不夺取麦克风录音；外屏撤回或退后台后停止解码与播放。
- [ ] 损坏 GIF、伪装扩展名、无视频轨的文件及超出处理能力的素材有明确提示，失败不留下半导入条目。

## 3. 拍摄和本地恢复

- [ ] 拍照、对焦、缩放工作；横竖屏预览和保存文件方向正确。
- [ ] 视频默认 1080p/30fps（设备支持时），开始/停止状态明确；停止后文件可完整播放。
- [ ] 允许麦克风时录像有声音，拒绝时仍可录无声视频。
- [ ] 相机权限拒绝时提示去设置，不反复弹系统请求。
- [ ] 相册追加权限拒绝时保留拍摄文件，授权后重试可成功保存，重复点击不会重复提交。
- [ ] 拍摄/保存中旋转、锁屏、切后台、来电或相机被系统占用，录制能够结束并保留已完成内容；返回时取景可恢复。
- [ ] 保存失败后退出重启，待保存文件和重试入口仍存在。
- [ ] 低存储空间时清晰提示，不删除此前未保存的文件。

## 4. 持续使用

- [ ] 连续运行取景+动画至少 10 分钟，记录发热、卡顿、内存异常或系统压力提示。
- [ ] 连续拍摄至少 10 张照片、3 段视频，保存条目与系统相册一致。
- [ ] 使用相同账号和 Bundle ID 覆盖安装升级，素材库及未保存队列保留。
- [ ] 配置续签后完成一次 Sideloadly 刷新，App 仍可运行，本地数据保留。
