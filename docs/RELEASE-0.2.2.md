# DuoCue 0.2.2 · 旋转卡住修复

用户反馈0.2.1翻转手机时整个 App 无响应。代码审查确认横竖屏采用不同视图分支，切换时会拆除并重接预览层；方向回调与布局还会同步修改相机连接。没有取得真机 hang 堆栈，因此不将某一个框架锁认定为已证实根因。

## 改动

- 横竖屏改用 AnyLayout，保留同一个原生预览和 session 连接，只改变排布。
- 在布局或系统方向通知期间仅缓存预览角；随后在主线程下一轮合并并应用最新值，避免同步重入布局/KVO。
- 旧预览断开或跨屏重建协调器时取消尚未执行的更新，避免旧回调写入新连接。
- 拍摄角只缓存，照片/录像开始前才应用，不再在每次旋转通知中重配采集输出。
- 保留0.2.1的实际传感器方向协调、0.2.0的图片/GIF/视频导入及猫猫图标。

## 验证

新增连续16次横竖布局切换测试，检查原生预览只创建一次且期间不拆除；新增4项延后执行、批量角度合并、旧回调取消、重入转为下一轮执行的测试。云端总计38项 XCTest，实际结果见验证记录。

模拟器验证覆盖生产布局和方向任务调度，无法证明真实摄像头/双屏系统不再卡死。覆盖更新后需在 Duo 上连续横竖转动、打开素材库再返回及合拢再展开确认。使用相同 SideStore 账号覆盖安装，不先卸载。
